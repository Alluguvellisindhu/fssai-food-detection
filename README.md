# 🛡️ Food Safety Risk Assessment using Machine Learning

> Project for FSSAI Internship - IT Division | Oct-Dec 2026 Batch

### 📌 Objective
To build an ML model that assesses risk level (Low / Medium / High) of food samples based on chemical, microbiological & labeling parameters, helping FSSAI prioritize inspections.

### 🧠 Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-learn, NumPy, Matplotlib
- **Models Used:** Random Forest, XGBoost, Logistic Regression
- **Dataset:** FSSAI Food Sample Data / Synthetic Food Safety Data

### ⚙️ Features
- Risk classification (Low, Medium, High)
- Key risk factor identification
- Visualization dashboard for risk patterns
- Model accuracy > 85%

### 📊 Workflow
1. Data Collection & Cleaning
2. Feature Engineering (pH, moisture, bacteria count etc.)
3. Model Training & Evaluation
4. Risk Prediction API

### 🔗 Use Case for FSSAI
This can be integrated into FoSCoS / Food Import Clearance System to auto-flag high-risk samples.
